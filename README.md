# Времячко

Рабочие часы по проектам — без ручного подсчёта.

Рассчитывает, сколько часов нужно затрекать по каждому проекту за один или несколько выбранных месяцев: с учётом процента загрузки, периода участия и отсутствий.

**[Открыть калькулятор](https://linturaven.github.io/worktimecalc/)**

## Возможности

- Выбор одного или нескольких месяцев в компактном раскрывающемся календаре с переключением года, включая месяцы разных лет и месяцы не подряд (до 24).
- Настройка продолжительности рабочего дня.
- До 20 проектов с названиями, процентами загрузки и индивидуальными датами начала и окончания.
- Загрузка производственного календаря через isDayOff API и учёт сокращённых дней.
- Несколько отсутствий: полный рабочий день или заданное количество часов в день.
- Итоги по проектам, норма периода, исключённые и доступные часы.
- Детализация по дням с подсветкой отклонений суммарной загрузки от 100%.
- Экспорт детализации в CSV.
- Выбор точности отображения: округление с настраиваемым числом знаков после запятой (от 0 до 15, по умолчанию 3) либо без округления. Внутренний расчёт и CSV не зависят от этого выбора.

Часы указаны десятичной дробью: **40,8 ч = 40 ч 48 мин**. В режиме без округления видны значения JavaScript, включая возможные погрешности двоичного представления дробей.

## Как пользоваться

1. Выберите режим «Один месяц» или «Несколько месяцев» и отметьте нужные месяцы. Настройте календарь страны и продолжительность рабочего дня.
2. Задайте количество проектов, их названия, проценты и периоды участия.
3. При необходимости добавьте отсутствия и задайте их даты.
4. Нажмите «Рассчитать» и проверьте сообщение об источнике календаря.
5. Посмотрите итог по проектам и детализацию; при необходимости скачайте CSV.

Изменения процентов, периодов и отсутствий пересчитывают результат автоматически.

## Как считается время

Расчёт выполняется для каждого дня выбранных месяцев. Промежутки между выбранными месяцами не учитываются. Границы периодов включены.

```text
Доступные часы = норма дня − часы отсутствий
Часы проекта = доступные часы × процент загрузки / 100
Итог проекта = сумма часов за дни его активного периода
```

В выходной норма равна нулю. В сокращённый день из обычной нормы вычитается один час. Суммарное отсутствие ограничено нормой дня. Проценты не нормализуются автоматически: сумма выше 100% приводит к перегрузке, ниже 100% — к нераспределённому времени.

### Пример

Для месяца с 22 рабочими днями по 8 часов и одним полным днём отсутствия доступно 168 часов:

| Проект | Загрузка | Часы за месяц |
| --- | ---: | ---: |
| Проект 1 | 25% | 42 |
| Проект 2 | 25% | 42 |
| Проект 3 | 50% | 84 |
| **Итого** | **100%** | **168** |

По умолчанию выбран текущий месяц по дате устройства, добавлен один проект с загрузкой 100%, отсутствий нет. Пример выше можно воспроизвести, выбрав сентябрь 2026 года и добавив отсутствие 25 сентября.

## Ваши данные остаются у вас

**Всё, что вы вводите — названия проектов, проценты, даты и отсутствия — обрабатывается на вашем компьютере или телефоне, прямо в браузере. Времячко не отправляет эти данные на сервер.** В приложении нет аналитики и отправки расчётов разработчику.

Настройки сохраняются в локальном хранилище браузера (`localStorage`): выбранные месяцы, проекты, проценты, периоды, отсутствия, страна, длина рабочего дня и округление. Закройте вкладку и вернитесь позже — всё останется на месте. На другом устройстве или в другом браузере настройки будут свои. Очистка данных сайта удалит сохранённые настройки.

Кнопка **«Сбросить настройки»** возвращает текущий месяц, один проект на 100%, отсутствие записей об отсутствиях и округление до 3 знаков. Кэш календаря сохраняется. Если браузер запрещает локальное сохранение, приложение сообщает об этом; расчёты продолжают работать.

Сетевые обращения всё же есть: браузер загружает сайт, логотип и GIF с GitHub Pages, а недостающие производственные календари — с [isDayOff](https://isdayoff.ru/). В запрос календаря входят только год, месяц, код страны и параметр сокращённых дней. Как при обычном открытии сайта, эти сервисы получают технические данные соединения, например IP-адрес. Названия проектов, загрузка и отсутствия в эти запросы не включаются.

Календарь сохраняется в браузере. Если его не удалось загрузить и сохранённой копии нет, используем ПН–ПТ без праздников и переносов и показываем предупреждение.

## Особенности текущей версии

- При изменении выбора месяцев проекты, охватывавшие весь прежний период, автоматически расширяются или сужаются до нового периода. Индивидуальные периоды и даты отсутствий сохраняются.
- Показатель «Рабочих дней» показывает дни по календарю до вычета отсутствий.
- Пересекающиеся частичные отсутствия складываются, но не могут превысить норму дня.
- Календарь в кэше пока не имеет срока обновления.

## Запуск и публикация

Код приложения находится в `index.html`: HTML, CSS и JavaScript без сборки и внешних библиотек. В папке `assets/` лежат логотип и анимация. Для локального запуска откройте файл в современном браузере. Для загрузки календаря нужен интернет.

Сайт опубликован через GitHub Pages из ветки `main`, корневой папки `/`. Обновление `index.html` в этой ветке запускает новую публикацию.

## Версия без интернета

**[Скачать Времячко для работы без интернета](https://linturaven.github.io/worktimecalc/timecalc-offline.zip)**

1. Скачайте ZIP-архив и распакуйте его целиком.
2. Откройте `index.html` в браузере. Установка не нужна.
3. Картинки и календарь России на **2026 год** уже в архиве — для них интернет не нужен. Источник встроенного календаря: isDayOff, данные получены 24 сентября 2026 года.

Другие годы и страны требуют загрузки календаря через интернет или ранее сохранённого календаря в этом браузере. Если календаря нет, приложение использует ПН–ПТ без праздников и переносов и предупреждает об этом. Это резервный расчёт, а не официальный календарь.

Настройки локальной версии и сайта могут храниться отдельно. Некоторые браузеры ограничивают сохранение настроек для локальных файлов — в таком случае появится сообщение. Чтобы получить обновлённую версию приложения или встроенного календаря, скачайте архив заново.
